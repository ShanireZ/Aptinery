# 像素風頭像生成器

## 提示詞

請根據我上傳的圖片，生成一張抽象像素風頭像。

核心目標：
不要做寫實複製，不要做 1:1 像素化還原，也不要保留原圖場景。
請提取主體最有識別度、最有記憶點的 3-5 個特徵，並將它們重新設計成一個獨立的復古像素頭像。

適用物件：
不限人物、寵物、玩具、食物、物品、交通工具、植物、動物或任何主體。
只要圖片裡有明確主體，都可以轉成像素頭像。

識別特徵提取：
請優先抓取最有辨識度的特徵，例如：
- 髮型、臉型、眼鏡、帽子、表情、配飾
- 毛髮、耳朵、尾巴、花紋、身體輪廓
- 服裝圖案、道具、姿態、動作
- 物體的形狀、顏色分區、結構特徵
- 任何一眼能記住的視覺符號

設計方式：
請主動進行抽象、誇張、Q版化、符號化、像素化重構。
不要把原圖翻譯成像素照片，而是基於原圖特徵重新設計一個頭像角色。

畫面要求：
- 1:1 正方形頭像
- 主體居中或偏中心
- 主體佔畫面主要面積
- 背景必須是純色背景
- 不要保留真實場景
- 不要風景、街道、建築、房間、桌面、草地、天空等原圖環境
- 只保留主體和極少量必要符號

像素風格：
- retro 8-bit pixel art
- 清晰像素塊
- 黑色或深色像素描邊
- 大色塊概括
- 強輪廓
- 極簡五官
- 圖標化頭像感
- 像復古遊戲角色 / NFT頭像 / 社交媒體頭像

顏色規則：
顏色可以大膽、有創意，不必真實。
請自動根據主體特徵隨機選擇高飽和撞色方案。

背景顏色必須隨機變化，可以從以下方向中自由選擇：
亮粉、湖藍、電光綠、熒光黃、紫色、橘紅、天藍、薄荷綠、珊瑚粉、深藍、亮橙、酸性綠、玫紅、青綠色。

主體顏色也可以創意強化：
頭髮、毛色、衣服、配飾、道具都可以進行高飽和改色或局部強調。
但要保留主體最核心的識別感。

配色邏輯：
- 主體和背景必須形成明顯撞色
- 如果主體偏深色，背景用明亮高飽和色
- 如果主體偏暖色，背景可用冷色
- 如果主體偏冷色，背景可用暖色
- 避免主體和背景顏色太接近
- 不要每次都黃底
- 不要每次都橙發
- 不要固定同一套配色範本

表情與氣質：
如果主體是人物或動物，可以根據原圖氣質自動設計表情：
呆萌、酷臉、震驚、壞笑、害羞、無語、開心、高冷、調皮。
不要每次都用同一種表情。

如果主體是物品：
不要強行加人臉。
優先保留物體輪廓和結構，只在不破壞識別度的前提下輕微擬人化。

禁止：
- 不要寫實
- 不要3D
- 不要厚塗
- 不要普通動漫插畫
- 不要真實照片質感
- 不要複雜背景
- 不要保留原圖真實環境
- 不要過度追求相似度
- 不要讓不同圖片生成同一個範本

最終效果：
生成一張高度抽象、顏色大膽、純色背景、像素感強、適合做頭像的 1:1 圖片。
它應該像一個被重新設計過的商業像素頭像IP，而不是原圖的像素翻版。

# 《寵物手繪肖像指南》

## 提示詞

請根據我上傳的寵物照片，創作一張「凌亂打圈線條輪廓風寵物插畫」。

整體風格要求：
只保留寵物主體，不要背景、不要傢俱、不要室內環境、不要道具雜物。
畫面為乾淨白底，主體居中或略偏中，保留充足留白。

插畫風格：
使用蠟筆 / 彩鉛 / 粗略手繪質感。
線條必須是凌亂、潦草、打圈式的輪廓線，不要乾淨工整的描邊。
輪廓由大量鬆散、重複、輕微錯位的線條組成，像隨手畫出的草稿線。
顏色不要鋪得太實，不要完整填色。
顏色只用零散、輕薄、跳躍的筆觸表現毛色、眼睛、鼻子、舌頭、耳朵、爪墊等特徵。
要讓大量白色紙面自然露出來，形成輕盈、透氣、未完成感。

主體要求：
必須準確保留照片中寵物的核心特徵，包括：
寵物品種/體型/毛量/耳朵形狀/臉型/眼神/毛色分佈/標誌性動作。
如果照片中有張嘴、吐舌、抬爪、趴著、坐著、尾巴姿態等明顯動作，需要保留。
整體要像寵物本人，而不是泛泛的卡通動物。

色彩要求：
根據照片真實毛色進行輕量表達。
黑色、灰色、棕色、白色、奶油色等毛色用凌亂線條和稀疏色塊表現。
眼睛、鼻子、舌頭、耳朵內側、爪墊等局部可以用更明確的顏色點亮。
顏色必須鬆散、凌亂、有手繪痕跡，不要厚塗，不要油畫感，不要寫實填滿。

構圖要求：
寵物主體完整、清晰、有識別度。
可以適度誇張寵物最可愛的特徵，比如大眼睛、蓬鬆毛、耳朵、舌頭、爪子。
整體像一張高級寵物手繪簽名頭像，乾淨、可愛、有紀念感。

文字要求：
在右下角添加寵物名字：{{寵物名}}
名字使用手寫感字體，像鉛筆或蠟筆隨手簽名。
文字不要太大，不要搶主體。
文字顏色以深灰、黑色或與寵物局部顏色呼應的淡色為主。
可以加一條很隨意的短下劃線，但不要裝飾過多。

畫幅比例：
{{畫幅比例，例如 4:5 / 1:1 / 3:4}}

禁止：
不要真實攝影風。
不要厚重塗色。
不要背景場景。
不要複雜裝飾。
不要卡通貼紙感。
不要向量扁平風。
不要過度精修。
不要把顏色鋪滿。
不要讓線條太乾淨。
不要把寵物畫成完全不同的動物。

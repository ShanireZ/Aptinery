# 手繪風格

## 提示詞

你是一名頂級時尚插畫師、人物速寫藝術家、電影分鏡視覺導演、復古雜誌插圖設計師、設計師草稿頁創作者。

請基於我上傳的照片，創作一張「真人可識別的手繪時尚漫畫素描 + 英文手稿批註 + 電影感觀察頁」風格插畫。

這不是照片濾鏡，不是照片做舊，不是把原圖簡單轉成水彩效果。
你必須像真正的插畫師一樣，重新繪製照片中的人物和環境：先用墨線建立人物輪廓、五官結構、服裝褶皺和場景透視，再用淡水彩上色，最後加入英文手寫批註和設計草稿線。

整體效果要像一張被手動畫出來的復古時尚插畫稿，而不是一張套了復古濾鏡的照片。

畫幅比例：{{保持原圖比例 / 4:5 / 3:4 / 1:1 / 5:2}}

場景氣質：{{travel / mountain / street / fashion / quiet / cinematic / relaxed / lonely / elegant / documentary，可留空}}

--------------------------------------------------
一、核心目標
--------------------------------------------------

將照片重新繪製成一張「真人可識別的手繪時尚漫畫素描」。

重點是“畫出來”，不是“濾鏡化”。

最終畫面必須具備：

- 明確的手繪墨線
- 重新繪製的面部輪廓
- 被線條塑造出來的五官
- 鉛筆速寫感的頭髮、帽子、衣服褶皺
- 手繪水彩上色
- 舊紙質感
- 英文手寫批註
- 設計師草稿頁氛圍
- 電影分鏡式觀察感

人物要像原照片，但必須看得出是插畫師手繪出來的，而不是原照片直接做舊。

--------------------------------------------------
二、人物重繪規則
--------------------------------------------------

人物必須重新繪製，而不是保留照片質感。

請重點重繪：

- 臉型輪廓
- 側臉線條
- 眉眼結構
- 鼻樑和鼻尖
- 嘴唇輪廓
- 下巴線
- 耳朵
- 頭髮走勢
- 帽子 / 眼鏡 / 髮飾
- 手部動作
- 服裝褶皺
- 揹包、圍巾、杯子、手機等關鍵道具

臉部要有清晰的插畫線條。
五官要像時尚漫畫或雜誌人物速寫中的五官：簡潔、乾淨、有線條感、有一點藝術化，但仍然保留真人相似度。

面部不能只是照片原臉加水彩濾鏡。
要像真正的手繪人物稿一樣，用線條畫出眼睛、鼻子、嘴巴、臉頰和下頜，讓人物看起來是被重新畫出來的。

--------------------------------------------------
三、手繪線條要求
--------------------------------------------------

線條是畫面的核心。

請使用：

- loose ink linework
- expressive pencil sketch lines
- visible hand-drawn contour lines
- cross-hatching
- sketchy facial structure lines
- fashion illustration line quality
- rough but elegant outlines
- delicate line details on face and clothing

人物輪廓線要比背景更明確。
臉部、手部、衣服褶皺、帽子、包、鞋子等位置要有明顯線稿。
背景可以更淡、更松，但也要有手繪結構，不要像照片背景。

線條要凌亂但剋制，像設計師草稿，不要過度乾淨，也不要亂成塗鴉。

--------------------------------------------------
四、上色方式
--------------------------------------------------

使用淡水彩和復古雜誌插圖式上色。

顏色來自原照片，但要重新手繪化：

- 皮膚使用淡赭色、淺肉色、暖灰陰影
- 衣服保留原照片主色，但降低飽和度
- 背景使用淡水彩塊面
- 陰影用灰褐色、藍灰色或墨水暈染表達
- 舊紙底色為米黃色或淺羊皮紙色

上色要有筆觸感、暈染感、留白感。
不要做成攝影級真實光影。
不要做成油畫厚塗。
不要做成 AI 平滑插畫。

--------------------------------------------------
五、場景處理
--------------------------------------------------

請保留照片裡最重要的場景記憶點，並重新畫成線稿 + 水彩。

如果是自然 / 山地 / 旅行場景：
- 保留山體輪廓、雲層、河谷、草地、岩石、道路、湖水、天空等結構
- 山體用淡水彩和速寫線表現
- 雲層可以鬆散、輕盈、有水彩暈染
- 人物線條比山和天空更重

如果是街頭 / 建築 / 店鋪場景：
- 保留牆面紋理、招牌、門窗、燈、陰影、街角結構
- 用線稿和低飽和水彩表現牆面質感
- 保留街拍瞬間感

如果是車內 / 室內 / 交通場景：
- 保留車窗、座椅、門板、玻璃反光、手機、包、手部動作、光線方向
- 用設計草稿線強調空間結構
- 讓畫面像電影分鏡中的一影格

如果是博物館 / 古蹟 / 歷史建築場景：
- 保留壁畫、柱子、石刻、樓梯、欄杆、牆面紋理和空間透視
- 用細密線稿表現歷史紋樣
- 用淡水彩保留石材、金色、赭石和舊牆質感
- 人物像在歷史空間裡的觀察者

--------------------------------------------------
六、英文手寫批註
--------------------------------------------------

畫面中只使用英文手寫文字。

不要中文。
不要中英混排。
不要中文標題、中文標註或中文清單。

英文批註要像設計師手稿、時尚插畫邊注、電影分鏡批註，而不是整齊海報排版。

可以加入：

- loose handwritten English notes
- cursive scribbles
- quick annotation marks
- arrows and underlines
- circled details
- fragmented mood notes
- tiny labels
- field-note style captions
- designer draft marks
- framing lines

批註內容根據照片環境自然生成，可以圍繞：

- posture
- silhouette
- outfit details
- gesture
- gaze direction
- hands
- cap / sunglasses / jacket / backpack / scarf
- mountain / cloud / river / road / stone / wall / sign / window / light / shadow
- mood
- scene rhythm
- cinematic frame
- quiet moment
- texture

--------------------------------------------------
七、不同場景的英文批註方向
--------------------------------------------------

自然 / 山地 / 徒步場景可以寫類似：

- “high altitude, low noise”
- “wind edits the plan”
- “clouds moving slower than thoughts”
- “backpack carries weight, eyes carry distance”
- “the mountains make people smaller”
- “quiet frame, loud view”
- “pause disguised as progress”
- “the road keeps going”
- “soft sky, sharp rocks”
- “small figure, large silence”
- “field note: breathe deeper”
- “not lost, just looking further”

街頭 / 建築 / 店鋪場景可以寫類似：

- “casual pose, serious outfit”
- “texture department: excellent”
- “good light, better attitude”
- “the wall is doing half the styling”
- “not posing, just passing dramatically”
- “outfit doing the talking”
- “shadow line works”
- “street frame, quiet mood”
- “small gesture, big character”

車內 / 日常 / 手機場景可以寫類似：

- “private mood, public window”
- “soft light through glass”
- “hands tell the scene”
- “somewhere between departure and reply”
- “the window keeps the outside quiet”
- “phone glow, travel pause”
- “waiting, scrolling, thinking”
- “small screen, large silence”
- “moving but still”

古蹟 / 博物館 / 歷史空間場景可以寫類似：

- “history in the walls”
- “standing inside a long sentence”
- “ancient lines, modern silhouette”
- “stone remembers everything”
- “quiet observer”
- “time carved into columns”
- “gold, dust, shadow”
- “small figure under old gods”
- “the walls speak in symbols”
- “museum light, slow thoughts”

這些只是方向參考。最終文字要根據照片裡的真實場景、人物狀態和視覺關係自然生成。

--------------------------------------------------
八、標題處理
--------------------------------------------------

頁面可以有英文標題，也可以沒有標題。

如果使用者填寫了頁面標題：
- 請把標題自然放進畫面空白處
- 標題必須使用英文
- 標題像手寫插畫頁標題，不像商業海報標題
- 可以用粗一點的黑色手寫字體
- 可以加下劃線、小星星、小箭頭、線框等輕微裝飾

如果使用者沒有填寫頁面標題：
- 可以不加大標題
- 只用英文小批註、箭頭、圈注和塗鴉完成畫面

標題不要遮擋人物臉部，也不要壓過主體。

--------------------------------------------------
九、畫面質感
--------------------------------------------------

整體風格關鍵詞：

hand-drawn fashion illustration, expressive ink sketch, watercolor character study, cinematic storyboard sketch, vintage magazine illustration, designer draft page, beige aged paper texture, visible pencil lines, hand-drawn face, ink contour lines, editorial illustration, observational drawing

畫面必須像：

- 手繪時尚插畫
- 復古雜誌人物速寫
- 電影分鏡草稿
- 設計師觀察頁
- 獨立插畫紙頁

畫面不應像：

- 照片濾鏡
- AI 一鍵水彩濾鏡
- 做舊照片
- 過度真實攝影
- 平滑數碼插畫
- 3D 繪製
- 真實筆記本頁面

畫面是一張獨立插畫紙頁，不做成真實筆記本頁面，不需要裝訂線、活頁孔、螺旋扣或書脊。

--------------------------------------------------
十、最終成圖標準
--------------------------------------------------

最終圖像必須達到：

1. 人物一眼能看出來自原照片
2. 人物臉部是重新手繪的，有明確線稿，不是照片濾鏡
3. 五官、頭髮、帽子、手部和衣服褶皺有明顯手繪線條
4. 姿態、服裝、道具和場景關係基本保留
5. 有復古插畫、電影分鏡、水彩墨線質感
6. 畫面中只出現英文手寫批註，不出現中文
7. 英文批註像設計師草稿和時尚插畫邊注
8. 整體鬆弛、有態度、有故事感
9. 輕微誇張但不恐怖、不畸形、不醜化
10. 像一位真正的時尚插畫師根據真人照片重新畫出的英文觀察手稿

請直接生成最終圖像。不要輸出分析過程，不要輸出解釋文字。

# 彩色新構成主義巨構海報

## 視覺風格原子

創作一張具有巨構感、震撼感和強烈幾何張力的彩色新構成主義海報。風格核心是巨大主體、極端尺度差、銳利方向動勢、高反差色塊、剋制文字和復古印刷質感。

## 風格基因

- 一張圖只保留 1 個核心主題、1 個核心主體、1 個視覺中心、1 個主要運動方向、1 個核心隱喻和 1 套獨立配色。
- 主體必須形成巨大壓迫感，佔據畫面 40%-80% 面積，或被畫面邊緣大膽裁切，或與小型陪體形成極端尺度反差。
- 優先使用巨大圓弧壓入畫面、超大主體局部特寫、對角線切割、強透視延伸、環繞式構圖、向中心匯聚、向上壓迫或紀念碑式邊緣裁切。
- 幾何元素包括巨大圓形或圓弧、三角形、楔形、長條色塊、放射線、軌跡線、重複細線、銳利切面、大面積純色背景和深色留空。
- 幾何元素必須承擔空間、節奏、方向和壓迫感，不作為裝飾堆疊。
- 主體可以適度幾何化、平面化、符號化、剪影化、局部放大、比例誇張和結構強化；必須清晰可識別，但不追求繁瑣細節。
- 人物保留識別度最高的輪廓、姿態、側臉、半身或局部特寫；產品可放大、裁切、旋轉、拆分或誇張透視；建築強化高度、體塊、邊緣和紀念碑感；動物保留關鍵輪廓與動作；天體優先做成超大局部或巨大圓弧；抽象概念轉化為單一清晰隱喻。
- 每次重新建立一套 3-4 種主要顏色的大膽限色系統：1 種主色佔 50%-70%，1 種爆點色集中用於關鍵主體、標題或幾何切面，1 種深色穩定結構，1 種淺色用於文字與留白。
- 色彩可以冷暖強碰撞、明暗強碰撞、高低飽和碰撞、互補或近互補碰撞、髒色與亮色並置、復古色與跳色並置。目標是大膽、陌生、衝突但成立。
- 可參考但不要固定使用：暗紫 x 黃綠色 x 陶土橙 x 米白，寶藍 x 桃紅 x 橄欖綠 x 淺米色，深棕 x 湖藍 x 芥末黃 x 奶油白，酒紅 x 青綠 x 土黃 x 炭黑，灰紫 x 橙紅 x 髒綠 x 象牙白，深藍 x 珊瑚粉 x 沙黃 x 黑色，墨綠 x 熒光黃綠 x 灰粉 x 米白，赭石 x 霧藍 x 淡金 x 深紫黑。
- 加入剋制的復古印刷質感：細微紙張顆粒、絲網印刷網點、輕微油墨不均、極輕微套色偏移、自然褪色和細小印刷紋理。

## 圖文關係

- 畫面最多保留主標題 1 處、副標題最多 1 處、輔助資訊最多 1 處；輔助資訊控制在 8 個漢字以內。
- 文字總面積不超過畫面 15%，主標題承擔第一視覺或與主體共同承擔第一視覺。
- 主標題使用粗體、窄體、壓縮字體或幾何字體，可以巨型放大、局部裁切、縱向排列、沿幾何邊緣排列、與主體咬合、沿圓弧或斜線佈局、穿插在前景與背景之間。
- 標題要像畫面結構的一部分，而不是單純貼在背景上。
- 閱讀順序必須明確：主標題、然後副標題、最後輔助資訊。

## 風格特有禁用項

- 不要讓主體以正常大小擺在畫面裡。
- 不要平均分佈顏色面積。
- 不要連續套用固定黃色背景或固定色組。
- 不要堆疊多組輔助文案或擴充成長說明。
- 不要把幾何元素當作無意義裝飾。
- 不要製造多個視覺中心、多套隱喻或多條主要運動方向。

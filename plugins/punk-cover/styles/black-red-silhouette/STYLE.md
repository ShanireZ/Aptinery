# 黑紅剪影

## 視覺風格原子

創作一張黑紅剪影風格封面。整體只使用紅、黑、白三種顏色：紅色負責空間和情緒，黑色負責主體和剪影，白色只用於標題、少量高光和關鍵點睛。畫面必須極簡、乾淨、有衝擊力，像一塊巨大的紅色舞臺螢幕，主體像舞臺動畫裡的黑色圖形符號。

## 風格基因

- 只使用紅、黑、白三種顏色。紅色佔主要面積，黑色形成主體輪廓，白色只做標題、少量高光和關鍵點睛。
- 背景是大面積純紅空間，不使用複雜背景、雜色、漸變、做舊、紙張顆粒、髒汙紋理或復古磨損。
- 每張圖只保留一個核心場景、一個主體動作和一個清晰隱喻。
- 主體必須以黑色剪影為主，輪廓清楚，細節剋制，不表現寫實人物臉，不追求真實攝影感。
- 主體場景必須比文字更重要，遠看先看到黑色剪影和紅色空間，近看再讀標題。
- 工具教學類優先使用“人正在使用工具”的場景表達。
- 電影主題類優先使用最經典的人物姿態、關係或標誌性場景表達。
- 金融主題類優先使用牛、曲線、上升結構、觀察者等簡潔符號表達。
- 速度主題類優先使用車輛、道路、遠方城市、速度線表達。
- AI 主題類優先使用人、螢幕、腦形符號、游標或極簡介面表達。
- 不為了設計感強行加入大手、鎖鏈、機械流水線或複雜裝置；只有這些元素和主題高度相關時才使用。

## 圖文關係

- 主標題使用白色或暖白色，字體清晰、簡潔、有力量。
- 標題必須清楚可讀，但保持克制，只作為輔助資訊，不成為畫面主角。
- 副標題比主標題小一檔，只作為補充說明。
- 除主標題和副標題外，不出現其他文字，不做資訊圖，不堆說明文字，不出現複雜 UI 文案。
- 橫版封面中，標題放在居中偏左或居中偏右，根據主體位置避讓；主體場景必須是第一視覺。
- 豎版封面中，標題放在最上方居中或最下方居中，不佔據過多空間；中間主體必須成為絕對主視覺。
- 中文使用現代黑體、幾何黑體、粗黑體或窄體黑體；英文使用清晰有力的 sans-serif、grotesk 或 condensed sans-serif。

## 風格特有禁用項

- 禁止出現藍色、紫色、綠色、棕色、灰髒色、金屬色或任何額外雜色。
- 禁止複雜漸變、霓虹光效、賽博藍光、真實攝影感、過多 UI 面板和複雜資訊圖。
- 禁止復古做舊顆粒、髒汙紋理、紙張顆粒、磨損邊緣或仿舊印刷效果。
- 禁止複雜背景、複雜人物五官、寫實人臉、裝飾性細節堆疊。
- 禁止讓文字壓過主體畫面，或讓文字成為唯一主視覺。

# 極簡輕科技

## 視覺風格原子

創作一張“極簡輕科技”封面：乾淨的純白 / 暖白 / 淺灰背景、大面積留白、現代超粗黑體標題，以及畫面中唯一的一個主視覺錨點。錨點要麼是輕微立體化的品牌 Logo，要麼是一枚抽象的柔和 3D 玻璃 / 漸變形體；柔和精緻的漸變只集中在這個錨點上，不鋪滿整張畫面。整體像高級輕科技產品封面或品牌概念海報，安靜、清晰、剋制，不要賽博朋克，不要密集 UI，不要拼貼，不要把畫面填滿。

## 整體風格

- 視覺識別來自四件事：大面積淺色留白、超粗現代黑體標題、單一主視覺錨點、錨點上的柔和漸變。
- 氣質是輕科技、產品感、乾淨、高級、剋制；像當代 SaaS / 工具 / 品牌發佈封面，而不是遊戲海報、營銷大促或科幻概念片。
- 平台適配、長文提煉、用途文案和通用封面約束由 `punk-cover` 負責；本 style 只擁有視覺語言本身。

## 畫幅與構圖

- 畫幅比例只用於決定構圖，絕不把比例數字、解析度數字或尺寸標註印進畫面。
- 橫版（如 5:2、16:9）優先：左側或偏左放置標題，右側或偏右放置唯一錨點；也可採用安靜的非對稱平衡，但必須保留明確呼吸空間。
- 豎版（如 4:5、3:4、9:16）優先：標題在中上區域，錨點在標題下方或一側，錨點尺寸收斂，不壓過標題。
- 正方形可居中或輕微偏側，但仍然只保留一個錨點，四周留白充分。
- 畫面主體只包含：淺色背景、可選標題文字、一個主視覺錨點、極輕的接觸陰影。不要第二主視覺，不要裝飾邊框，不要角落小圖標陣列。

## 文字系統

- 當畫面文字不是「無文字」時，畫面中的可見文字必須與使用者給定文案完全一致，不得改寫、擴寫、翻譯或增減字元。
- 當畫面文字為「無文字」時，畫面中不出現任何標題或說明文字，只保留淺色背景與唯一錨點。
- 中文標題使用現代超粗黑體 / 無襯線黑體，字形飽滿、邊緣乾淨、字距自然；顏色為黑色或近黑，不做漸變字、描邊字、發光字或立體擠壓字。
- 英文若作為標題的一部分出現，同樣使用粗體無襯線，並服從同一排版層級；不要額外添加使用者未提供的英文副標、口號或水印。
- 標題以清楚易讀為準，可醒目但不粗暴佔滿畫面；不要斜排、豎橫混排、文字穿過錨點、文字貼邊或小字說明堆疊。

## 主視覺錨點

- 整張圖只能有一個主視覺錨點。錨點是畫面第二焦點（有標題時）或唯一焦點（無文字時）。
- 分支規則：
  - 若「是否提供 logo」為是，並且使用者提供了 logo：優先走 Logo 錨點分支。
  - 若未提供 logo，或使用者明確偏好抽象形體：走抽象錨點分支。
- 錨點必須輕、淨、集中；漸變、高光、半透明和輕微立體感都只發生在錨點內部及其緊鄰陰影，不擴散成背景光汙染。

## logo 規則

- Logo 需可識別：保留核心圖形、比例和品牌識別特徵，不要重繪成陌生符號，不要偽造未提供的商標文字。
- 允許輕微立體化 / 輕擬物處理：圓角厚度、柔和高光、細膩接觸陰影、輕微玻璃或軟塑膠質感均可，但必須剋制，不能變成誇張玩具、重金屬或賽博徽章。
- Logo 可作為錨點本體，也可被輕輕嵌入一枚柔和的玻璃 / 漸變載體中；無論哪種，仍然只算一個錨點。
- 若 logo 使用說明有指定（位置、原色保留、禁止改色等），嚴格遵守；未說明時，可在選定漸變色系內做剋制的光色呼應，但不得破壞識別。

## 抽象錨點

- 抽象錨點應是一枚柔和的 3D 玻璃體、透鏡層疊、半透明橢圓、軟流體或精緻漸變形體；表面光滑、邊緣圓潤、通透或霧面通透。
- 形體簡潔，通常由一到三層交疊的軟幾何構成，表達輕科技、透明、流動或能量匯聚；不要複雜機械零件，不要電路板，不要擬物手機 / 電腦整機。
- 錨點下方可有非常輕的漫射接觸陰影，以建立完成實作感；陰影不能重、不能髒、不能拉出長投影戲劇光。

## 色彩與漸變

- 背景固定在純白、暖白或非常淺的冷灰 / 暖灰；背景本身不做大面積彩色漸變、網格、噪聲或光斑。
- 漸變只服務錨點。根據「漸變色系選擇」完成實作：
  - 自動選擇：依據內容主題與配色補充說明，優先藍綠、冰川、銀藍或低飽和冷色等輕科技方向。
  - 藍綠系：天空藍 → 青綠 / 青藍過渡。
  - 藍紫系：靛藍 → 霧紫。
  - 紫粉系：霧紫 → 柔粉，保持低噪高級，避免甜俗。
  - 青綠系：湖綠 → 青綠。
  - 薄荷系：薄荷青 → 淺青綠。
  - 冰川系：冰藍 → 冷白青。
  - 銀藍系：銀灰高光 + 冷藍。
  - 金橙系：暖金 → 柔橙，剋制使用，避免廉價促銷感。
  - 黑金系：近黑錨點結構 + 金色高光邊緣，仍需留白底，不要暗黑整版。
  - 低飽和暖色系：霧杏、暖灰、淡陶色等低飽和暖調。
  - 低飽和冷色系：霧藍、灰青、鼠尾草綠等低飽和冷調。
  - 其他：嚴格按配色補充說明執行。
- 配色補充說明用於微調；若與所選色系衝突，以使用者補充說明為準，但不得破壞淺色留白底和單一錨點原則。

## 材質與光影

- 材質關鍵詞：柔和玻璃、磨砂液態、細膩漸變塑料、輕擬物、乾淨棚拍感。
- 光線為明亮、柔和、接近頂光 / 前側柔光的產品攝影光；錨點內部可有通透高光與輕微折射，但不要強霓虹、不要硬邊聚光、不要體積光掃過全畫面。
- 陰影只服務錨點完成實作，保持短、淡、乾淨。

## 輸出目標

- 適合作為科技產品封面、工具教學封面、品牌概念海報、公眾號 / X / 影片橫版頭圖，以及需要乾淨現代感的豎版海報。
- 最終畫面應一眼可讀：淺色留白 +（可選）超粗黑標題 + 唯一漸變錨點。

## 風格特有禁用項

- 不要賽博朋克、霓虹描邊、故障風、粒子爆炸、強發光描邊或暗黑科幻裝甲。
- 不要密集 UI、儀表盤、程式碼雨、視窗疊層、資訊圖、流程圖、圖標宮格或截圖拼貼。
- 不要多個主視覺錨點、多個 Logo、裝飾插畫人物、複雜場景或把畫面填滿。
- 不要在畫面中寫出畫幅比例、尺寸數字、水印、提示詞原文或使用者未提供的說明小字。
- 不要漸變鋪滿背景、不要彩色大色塊爭搶標題、不要立體擠壓標題、不要書法體 / 圓體 / 卡通裝飾字體。

# 科研期刊概念

## 視覺風格原子

創作一張科研期刊封面式概念視覺。風格核心是原創科學主視覺、機制暗示、材料或生命科學質感、高級配色和專業編輯版式。

- 版式偏好：{{自動判斷 / 大主視覺 / 極簡封面 / 暗色氛圍 / 淺色高級 / 中心主體 / 斜向構圖 / 微觀世界 / 宏觀隱喻 / 結構剖面}}

## 風格基因

- 視覺像頂級科研期刊封面，但不復制真實期刊名、Logo、官方識別元素或固定版式。
- 主體可來自細胞、蛋白、神經網路、材料晶格、微流控、藥物遞送、機器人系統、光學結構、生態模型、能量場或工程剖面。
- 畫面應暗示研究物件和機制，而不是畫完整實驗流程。
- 可使用微觀世界、宏觀隱喻、結構剖面、懸浮主體、科學裝置、光場、粒子、透明材料和高精度繪製。
- 配色可以剋制高級，也可以高飽和科研封面色，但必須有層次和專業感。

## 圖文關係

- 標題和副標題像科研編輯版式的一部分，少量、清楚、留白得當。
- 科學主體必須與主題機制相關，不能只是抽象科技背景。
- 若需要文字，文字應避開主體關鍵結構，並與網格、邊距和視覺焦點協調。

## 風格特有禁用項

- 不要直接模仿真實期刊封面。
- 不要使用普通藍紫科技背景、隨機 DNA、隨機芯片或無關實驗器材。
- 不要把科學機制畫成密集說明圖。

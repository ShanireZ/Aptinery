# 超大標題圖文穿插

請根據使用者提供的「標題」或「文章內容」，生成一張具有強烈編輯設計感的海報。

## 使用者輸入

- 內容：{{一句標題 / 一段文案 / 一篇文章}}
- 圖片比例：{{9:16 / 4:5 / 3:4 / 1:1 / 16:9 / 5:2 / 其他指定比例}}

## 任務目標

生成一張“超大標題 × 單一主體 × 圖文穿插 × 有呼吸感”的編輯型海報。

這不是普通的“圖片上加字”，而是讓文字真正進入畫面，和主體形成前後遮擋、穿插、咬合的關係。

整體要像：

- 設計海報
- 雜誌封面
- 展覽視覺
- 品牌主視覺

不要像：

- 普通公眾號封面
- PPT 封面
- 電商海報
- 資訊流廣告
- 廉價範本圖

## 一、先理解內容

先自動分析使用者輸入的內容，提煉出：

1. 這段內容最核心的主題；
2. 最值得被放大的主標題；
3. 最適合視覺化呈現的主體；
4. 這張海報更適合傳達什麼氣質。

如果輸入的是文章，而不是明確標題，自動提煉一個適合海報展示的短標題。

標題控制原則：

- 中文主標題優先控制在 2—8 個字；
- 英文主標題優先控制在 1—4 個單詞；
- 標題要短、準、有力量，適合大字排版；
- 不要把完整長句直接當作主標題。

如果原文裡有一句很適合做輔助說明，可以提煉一句極短副文案；如果沒有，就不要硬加。

## 二、主體選擇規則

根據主題，自動選擇最合適的主視覺主體。主體不固定為某一種材質或某一種風格，可以是：

- 真實人物；
- 真實生活場景中的人或物；
- 單一核心物件；
- 扁平插畫；
- 剪影；
- 拼貼；
- 幾何抽象圖形；
- 具象與抽象結合的概念圖形。

優先原則：

1. 主體必須和標題語義直接相關；
2. 主體輪廓要清晰，適合和大字穿插；
3. 主體風格要根據主題自動變化；
4. 不要長期重複同一種主體語言。

主體風格分配邏輯：

- 如果主題偏生活方式、運動、工作、情緒、消費、日常，優先使用真實人物、真實動作、真實場景或真實物件；
- 如果主題偏設計、文化、審美、書籍、展覽，可以使用插畫、拼貼、剪影或圖形化表達；
- 如果主題偏哲思、隱喻、抽象概念，可以適度抽象化，但仍要保留一個明確主體；
- 如果主題偏科技、AI、系統、演算法、未來，可以更概念化，但不要預設全部做成金屬風。

重要限制：不要把“設計感”簡單理解為金屬雕塑、機器人、鉻麵人像或機械頭部。設計感來自圖文關係、版式層級和主體選擇的準確性，而不是固定材質。

預設不要：

- 每次都生成金屬人；
- 每次都生成雕塑頭像；
- 每次都生成機器人；
- 每次都生成未來感假人。

如果用人物：

- 人物動作自然；
- 姿態可信；
- 保留真實感、生活感、現場感；
- 不要遮住眼睛、鼻子、嘴巴等關鍵部位。

如果用抽象圖：

- 保持一個明確視覺焦點；
- 不要做得太散、太碎、太裝飾化。

整張畫面只保留一個主視覺焦點。如需多人，也只能圍繞同一個動作或同一個主題形成一個整體焦點，不要變成群像拼貼。

## 三、構圖核心規則

整張圖的固定構圖語言為：

1. 超大標題跨越畫面；
2. 一個核心主體佔據視覺中心；
3. 標題與主體發生真實前後穿插；
4. 資訊量剋制；
5. 畫面有留白、有呼吸感。

關鍵詞：

- type over image
- interleaved typography
- foreground-background layering
- editorial poster
- modern graphic design
- magazine cover aesthetic

固定的是“圖文關係”，不是固定主體類型，也不是固定配色範本。

## 四、最重要：圖文穿插規則

主標題必須真正參與構圖，而不是簡單蓋在圖上。

必須形成清晰的穿插關係：

- 一部分文字在主體後面；
- 一部分文字在主體前面；
- 主體局部遮擋文字；
- 文字局部壓在主體前面；
- 形成明確的前景 / 中景 / 後景層次。

要求：

- 文字與主體之間要有真實咬合感；
- 即使有遮擋，標題依然要可讀；
- 遮擋關係要經過設計，不要胡亂蓋住；
- 不要整行半透明字；
- 不要只做“一個人物壓在一整排字前面”的簡單關係；
- 不要把背景字與前景字機械地分成上下兩塊；
- 讓同一標題內部的字、詞或局部筆畫交替換層，至少出現兩次清晰的前後關係切換；
- 在核心重疊區域同時看見“主體遮字”和“字壓主體”；
- 不要顯得扁平，要體現明顯空間層次。

文字和主體要互相進入彼此的空間，而不是簡單疊加。

## 五、標題排版規則

主標題必須是畫面中最大的視覺元素之一。

要求：

- 使用超大字號；
- 可以跨越整個畫面；
- 可以分行；
- 可以斷行；
- 可以局部超出版面；
- 可以局部被裁切；
- 可以與主體緊密咬合。

字體氣質：

- 粗體；
- 高識別度；
- 現代感；
- 幾何感；
- 無襯線；
- 平面設計感強。

不要使用：

- 手寫體；
- 花體；
- 書法體；
- 幼稚可愛字體；
- 過度裝飾字體。

標題應該大膽，但不要因為做效果而影響識別。

## 六、版式與留白

整體版式要剋制，不要過滿，不要塞太多輔助資訊。

要求：

- 保留明顯留白；
- 給主標題和主體足夠呼吸感；
- 讓視線有停頓區；
- 不要把每個角落都填滿；
- 不要做成滿版轟炸式排版。

輔助資訊要少：

- 最多一條短副文案；
- 最多少量小字；
- 不要堆很多英文碎句；
- 不要加大段說明文字；
- 寧可留白，也不要亂填。

整張圖資訊層級最多三級：

1. 超大主標題；
2. 核心主體；
3. 極少量輔助資訊。

## 七、比例適配規則

不要把同一套構圖生硬套進所有尺寸。根據指定比例自動調整版式。

- `9:16`：縱向張力更強，標題可上下分區，主體可居中或偏上；
- `4:5`：適合封面感最強的排版，主體居中，標題圍繞主體；
- `3:4`：保持均衡，標題與主體形成明顯穿插；
- `1:1`：構圖集中，主體與大字更緊密；
- `16:9`：橫向展開，主體可偏左或偏右，標題橫向拉開；
- `5:2`：橫幅感更強，適合長標題拆分、單一主體、更多留白和橫向延展。

無論什麼比例，都要保持：

- 一個主標題；
- 一個主視覺焦點；
- 明確層級；
- 清晰穿插。

## 八、配色規則

不要固定成藍色背景、粉色或紅色輔助資訊。配色要根據主題自動決定。

原則：

- 每張海報控制在 2—4 種主要顏色內；
- 保持高對比、高識別度；
- 配色有審美，但不過度花哨；
- 配色服務於主題氣質。

可以是：

- 黑白灰；
- 米白 + 黑 + 橙；
- 深綠 + 米白；
- 酒紅 + 奶白；
- 淡粉 + 深紫；
- 冷灰 + 電藍；
- 土黃 + 棕；
- 其他合理方案。

強調色只用於小字、細線、節點或局部強調，不要讓輔助色搶走主標題和主體的風頭。

## 九、輔助圖形元素

允許加入少量輔助圖形，增強編輯設計感，例如：

- 細線；
- 圓弧；
- 節點；
- 短橫線；
- 小型幾何軌跡；
- 極少量網格或標記。

要求：

- 很剋制；
- 數量少；
- 只做輔助；
- 不要喧賓奪主；
- 不要做成複雜科技面板。

## 十、最終效果要求

最終畫面必須滿足：

- 一眼能看出“大字進入畫面”；
- 標題與主體有真實前後穿插；
- 畫面不是平鋪疊加，而是有空間層次；
- 主體和標題都強，但不過滿；
- 畫面有呼吸感；
- 視覺風格統一；
- 審美現代、乾淨、利落、有衝擊力。

優先保證以下四件事成立：

1. 超大標題；
2. 單一主視覺焦點；
3. 明確圖文穿插；
4. 留白與呼吸感。

這四件事比花哨細節更重要。

請直接輸出最終海報。

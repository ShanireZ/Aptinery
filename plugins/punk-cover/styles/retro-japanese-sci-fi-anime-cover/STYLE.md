# 復古日本科幻動畫

## 視覺風格原子

創作一張具有 90 年代日本科幻賽璐璐動畫關鍵影格感的封面。風格核心是標題卡式第一視覺、強烈限色、高飽和純色色塊、鋒利手繪線稿、硬邊賽璐璐陰影、誇張透視、強烈明暗對比和輕微膠片顆粒。可以借鑑復古科幻動畫標題卡、紫綠機甲配色和賽璐璐質感的視覺語言，但不能複製任何既有作品的角色、機體、標誌、標題或具體場景。

## 風格基因

- 先理解主題的核心矛盾、情緒和動作，再轉化為 1 個核心隱喻、1 個主要主體和 1 個正在發生的動作。
- 每張圖只允許 1 個視覺中心、1 個核心隱喻、1 個主要主體和 1 個主要動作；刪除會分散注意力的第二概念。
- 畫面必須具有高飽和純色色塊、鋒利手繪線稿、硬邊賽璐璐陰影、誇張透視、強烈明暗對比、輕微膠片顆粒和復古動畫關鍵影格感。
- 只從以下顏色中選擇：深紫色 #5F2A62、熒光綠色 #8BD450、深藍黑色 #1D1A2F、警示黃色 #F5C024、亮紫色 #965FD4、經典橙色 #F47A16、少量黑色和米白色。
- 每張圖只使用 1 個主背景色、1 個次級主色和 1 個小面積強調色；不要平均使用全部顏色，不要增加其他顏色，不要大面積漸變。
- 自動判斷主體類型時，人物、心理、情緒、關係、社會、成長類主題優先使用人物；AI、工具、技能、系統、方法、程式碼、產品、知識類主題優先使用無人物畫面，或人物與裝置交互。
- 有人物時，人物必須處在明確動作和處境中，例如掙脫、拉扯、切斷、穿越、推動、阻擋、啟動或重組；不要靜止擺拍，不要複製既有動畫角色造型。
- 無人物時，不能出現人物、人體剪影、手部或人臉；使用程式碼、頁面、檔案、卡片、模組、裝置或空間結構表達主題，並表現展開、轉化、爆發、拼合、穿越、啟動或重組。
- 無人物畫面不要只放靜止圖標、圓環、門、立方體或程式碼符號；主體結構必須正在變化。
- 只有主題涉及循環、持續迭代、長期主義、無限可能或自我進化時，才允許使用 infinity 符號；它必須成為場景結構、運動軌跡或系統閉環的一部分，不能只是裝飾。
- 構圖必須根據畫幅比例重新設計，不直接裁切同一張圖。橫版優先左標題右畫面或右標題左畫面，強調橫向運動和空間縱深；方形或 4:3 使用上下錯位或對角穿插；豎版優先上標題下畫面、側邊縱排標題或主體沿縱向空間運動。

## 圖文關係

- 主標題必須是第一視覺，準確、完整、清晰可讀，不能貼邊；縮小後仍能看清。
- 中文標題使用修長、鋒利、高對比的明朝體、宋體或 Mincho 風格；英文標題使用 Didot、Bodoni 或 Mincho 式高對比襯線體。
- 標題可以分行、縱排、錯位或與畫面穿插，但不能犧牲字形識別；標題氣質應接近復古科幻動畫標題卡，而不是普通黑體、圓體或現代 UI 字體。
- 除主標題外，最多隻允許 1 行副標題或 1 行極小英文短句。
- 不要出現編號、日期、版本號、條形碼、參數、步驟列表、資訊卡片、大量小字或複雜 UI。
- 所有文字處於安全區域，關鍵動作不被裁切，畫面只保留一個視覺中心。

## 風格特有禁用項

- 不要 3D、攝影寫實、現代賽博朋克、普通扁平插畫或企業科技風。
- 不要複製任何具體動畫作品的角色、機體、標誌、標題、臺詞或具體場景。
- 不要使用普通黑體、圓體、現代 UI 字體或弱標題層級。
- 不要平均使用全部固定顏色，不要添加其他顏色，不要使用大面積漸變。
- 不要靜止擺拍、無動作主體、裝飾性符號堆疊或多個視覺中心。
- 不要讓輔助資訊超過一行，不要用複雜 UI 或大量小字解釋主題。

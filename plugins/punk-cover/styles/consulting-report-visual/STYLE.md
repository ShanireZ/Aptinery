# 諮詢報告視覺

## 視覺風格原子

創作一張高端管理諮詢報告式視覺封面。風格核心是“文字主導 + 標題結構重構 + 單一商業隱喻 + 瑞士現代主義網格 + 剋制但完整的封面層次 + 專業配色”。

這不是普通 PPT、解釋型資訊圖或粗體自媒體封面。觀眾首先看到經過設計重構的核心詞，其次才看到完整標題和商業隱喻。圖形必須從文字結構中生長，而不是作為獨立圖表擺在標題旁邊。

## 風格基因

- 麥肯錫式理性氣質、高端報告封面感、瑞士現代主義網格和 boardroom-ready 的資訊層級。
- 白底或極淺冷灰底，保留大面積乾淨留白，但留白必須經過設計；使用可見但剋制的網格、透視線、座標、輪廓、閾值或分析標註組織空間。
- 使用頁眉、頁腳、細邊框、報告索引、年份、章節標籤、座標刻度等少量版式傢俱建立報告感，但不得形成內容頁。
- 畫面只使用一個核心商業隱喻，例如戰略路徑、閾值、防線、斷層、座標、收束點、視窗、矩陣邊界或價值階梯。
- 圖形應簡潔精準，只保留極細結構線、少量節點、一個方向箭頭或一個關鍵強調點，不展開為完整說明結構。
- 配色以白、深藍、冷黑、冷灰、銀灰為主；最多使用一種少量藍、橙、紅或綠作為決策點、風險點或終點強調。

## 封面資訊密度

- 封面只保留一個主視覺核心詞、一個商業隱喻、一個完整但剋制的小標題系統和極少量標籤。
- 必須有明確而單一的視覺中心，資訊量剋制，留白充足，但畫面不能只剩一個孤立詞語和空白背景。
- 使用者提供的完整標題或副標題必須作為清晰可見的 B 層出現，不能省略或縮小到無法承擔語義。
- 背景至少建立一套連續的細線空間系統，例如單點透視線、同心風險輪廓、斷層線、座標軸、建構網格、路徑殘影或少量分析標註；這些結構應覆蓋並連接畫面，而不是零散裝飾。
- 可以圍繞同一個隱喻放置 2–4 個極短的背景註解或座標標籤，但它們不能組成步驟列表、卡片模組或流程。
- 不要把文章的章節、步驟、觀點清單或分析框架全部畫出來。
- 不要生成三步、四步、五步流程，不要展開完整漏斗、矩陣、儀表盤、路線圖或節點時間線。
- 如果畫面看起來像在“解釋方法”，而不是在“提出一個高級商業觀點”，說明已經偏離該風格。

## 長標題分層

當使用者提供較長標題時，必須拆成三層：

1. A 層 / 主視覺核心詞：
   - 從完整主題中提煉 2–8 個最有張力、最適合結構化重構的中文字元。
   - A 層可以很大，但字重必須剋制，避免粗黑、壓迫和社媒海報感。
   - A 層承擔畫面的商業隱喻。
2. B 層 / 完整標題：
   - 完整保留使用者輸入標題。
   - 放在頁眉、邊緣資訊欄、副標題區或報告標題帶中。
   - 字號明顯小於 A 層，清晰可讀但不爭奪視覺中心。
3. C 層 / 報告標籤：
   - 只保留 1–3 個極短標籤、年份或欄目索引。
   - 像諮詢報告版式系統的一部分，不做徽章、按鈕或社交媒體標籤。

不得為了“主標題完整”而把整個長標題做成一塊巨型粗黑文字。完整性由 B 層承擔，視覺衝擊由 A 層承擔。

## 圖文關係

- A 層核心詞必須成為畫面主體結構，而不是普通標題。
- 根據語義對文字做切割、鏤空、錯位、分層、收束、路徑化、框架化、矩陣化、斷層化或空間化重構。
- 戰略路徑可以進入字形內部，斷層可以切開筆畫，座標可以成為字的骨架，視窗可以出現在負空間中，收束線可以從字中延伸到單一消失點。
- 商業隱喻必須嵌入文字，改變字形結構或從字形中生長；禁止在普通標題旁邊另放一個獨立圖標、泡沫、流程圖或矩陣。
- B 層完整標題和 C 層標籤像報告封面小字系統，數量剋制、層級明確。

## 字體行為

- 中文使用現代黑體、宋黑混合或剋制的現代無襯線氣質；英文使用 Helvetica、Neue Haas Grotesk、Univers 或 Swiss-style sans-serif 氣質。
- 主視覺文字可使用常規至中等字重、細線字、半鏤空字、結構字或輪廓與實體混合字。
- 字體可以巨大，但不能過度粗黑、過度壓縮、形成沉重文字牆或廉價標題黨視覺。
- 優先通過結構、空間、尺度、負空間和透視製造張力，而不是相依 extra-bold 字重。
- 保持中文準確、完整可辨，不使用亂碼、偽字或破壞識別的過度扭曲。

## 空間與構圖

- 優先採用寬闊的橫向報告封面結構、嚴格網格和大面積負空間。
- 可使用單點透視、遠處收束點、薄片式空間層、細線座標或從文字底部延伸出的路徑，建立理性而具有方向感的空間。
- 背景結構線必須達到可感知的視覺存在：主網格、次級透視線、風險輪廓和邊緣刻度共同構成完整空間，而不是只留下極淡、幾乎看不見的輔助線。
- 允許用半透明同心圓、波紋、弧線或泡沫邊界暗示風險與預期擴張，但必須與標題字形、路徑或座標系統發生結構關係，不能成為孤立插圖。
- 允許將 2–4 個文章核心維度作為極小註解散佈在同一座標場中，例如技術突破、行業複製、組織採用、商業兌現；它們是背景分析標註，不是四步流程。
- 視覺隱喻只有一個；其餘結構線只用於建立秩序。
- 圖形必須服從標題，不能把畫面切成多個同等權重的模組。
- 頁眉、頁腳和邊緣資訊帶可以存在，但必須輕、薄、小、準。

## 色彩與質感

- 主色：白、深藍、冷黑、冷灰、淺灰、銀灰。
- 強調色只選一種，並且只用於一個風險點、決策點、價值點、終點或關鍵箭頭。
- 禁止大面積高飽和暖色、藍紫霓虹、賽博朋克光效、彩虹漸變和廣告式發光。
- 使用乾淨啞光紙面、輕微印刷顆粒、精準細線和極淡空間陰影；避免玻璃擬態、塑料 3D 和通用科技 HUD。

## 風格特有禁用項

- 不要生成虛假詳細資料、虛構複雜圖表或密集小字。
- 不要把完整長標題作為巨型 extra-bold 文字塊。
- 不要使用粗黑、擁擠、壓迫性的社交海報標題。
- 不要把封面做成三步以上流程、節點時間線、完整漏斗、完整矩陣、儀表盤或方法論說明頁。
- 不要讓結構圖搶走標題層級，也不要讓圖形和標題彼此獨立。
- 不要堆放大量圖標、箭頭、節點、標籤、模組或說明文字。
- 不要讓一個孤立核心詞漂浮在近乎空白的背景中，也不要省略使用者要求的完整標題或副標題。
- 不要使用廉價商務範本、握手照片或無關辦公場景。

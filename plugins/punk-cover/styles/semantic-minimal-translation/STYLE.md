# 語義轉譯極簡

## 視覺風格原子

把輸入的詞、短句或概念轉譯成一張高級極簡圖形海報。文字不是說明標籤，圖像也不是獨立插畫；文字、主體、承載面、空間關係和少量色彩必須共同構成一個準確表達語義的視覺句子。

- 主題詞 / 主標題：{{主題詞}}
- 核心文字 / 單詞 / 詞組 / 字母：{{核心文字}}
- 畫幅比例：{{畫幅比例}}
- 文字語言：{{中文 / 英文 / 中英混排}}
- 可選補充語境：{{補充背景，可留空}}
- 可選情緒傾向：{{情緒傾向，可留空}}
- 可選禁用元素：{{不想出現的元素，可留空}}
- 是否允許輔助文字：{{允許 / 不允許}}
- 輔助文字關係說明：{{輔助文字說明，可留空}}

## 風格基因

- 極簡主場景，清晰承載面，1-3 個關鍵人物、物體或動作。
- 巨型核心文字成為畫面骨架，像牆體、舞臺、屏障、地形、容器或情緒壓力面。
- 主體必須與文字發生關係：站在字前、嵌入字內、穿越字形、被字阻隔、依附承載面或借用負空間。
- 配色控制在 2-4 種主色關係內，紙張感、印刷感、版畫感、輕微顆粒和剋制紋理優先。
- 大面積留白可以存在，但留白必須服務語義張力。

## 圖文關係

- 核心文字必須清晰可讀，併成為第一視覺。
- 輔助文字只在被允許時出現，且必須直接深化主題，不能使用隨機編號、假出版資訊、無關座標或裝飾性句子。
- 若主題抽象，選擇具體可見的物件和動作承載語義；若主題具體，通過尺度、距離、遮擋、對峙、給予、等待或穿越關係製造更深層含義。

## 風格特有禁用項

- 不要把詞語當普通標題貼在插畫上。
- 不要讓圖像和文字分離。
- 不要堆疊元素、複雜背景、廉價漸變或無意義裝飾。
